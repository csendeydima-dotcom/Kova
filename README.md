# Kova

Kova — мінімалістичний робочий простір для фрилансерів. Тут можна вести
проєкти, бюджети та задачі без перевантажених таблиць і зайвої навігації.

## Що реалізовано

- публічна адаптивна сторінка продукту;
- власна реєстрація та вхід через email і пароль;
- додатковий вхід через ChatGPT;
- персональний кабінет і автоматичне створення профілю;
- проєкти та задачі з постійним зберіганням у Cloudflare D1;
- перевірка власника даних і валідація запитів на сервері;
- захист від міжсайтових запитів і набір security headers;
- PBKDF2-хешування паролів, HttpOnly-сесії та обмеження спроб входу;
- Open Graph картка для красивого прев’ю посилання.

## Локальний запуск

Потрібен Node.js 22.13 або новіший.

```bash
npm install
npm run dev
```

Корисні команди:

```bash
npm run typecheck
npm run build
npm test
```

У локальному режимі публічна сторінка працює одразу. Для авторизації та
персональних даних потрібне D1-середовище Sites.
